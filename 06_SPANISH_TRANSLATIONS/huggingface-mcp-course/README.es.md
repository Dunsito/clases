# El curso de Model Context Protocol (MCP)

<div align="center"> <a href="README.md">🇺🇸 English</a> | <a href="README_vi.md">🇻🇳 Tiếng Việt</a> </div>

## Contenido

El curso tiene 4 unidades. Te llevarán **desde los fundamentos de Model Context Protocol hasta un proyecto final que implementa MCP en una aplicación de IA**.

Regístrate aquí (es gratis) 👉 [Próximamente]

Puedes acceder al curso aquí 👉 [Próximamente]

| Unidad | Tema | Descripción |
| ------- | --------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| 0 | Bienvenida al curso | Bienvenida, pautas, herramientas necesarias y visión general del curso. |
| 1 | Introducción a Model Context Protocol | Definición de MCP, conceptos clave y su papel al conectar modelos de IA con datos y herramientas externas. |
| 2 | Construir con MCP: desarrollo práctico | Aprende a implementar clientes y servidores MCP con los SDK y frameworks disponibles. |
| 3 | Inmersión en el protocolo MCP | Explora funciones avanzadas de MCP, su arquitectura y patrones de integración reales. |
| 4 | Unidades extra y colaboraciones | Temas especiales, bibliotecas de socios y proyectos de la comunidad. |

## Requisitos previos

* Comprensión básica de los conceptos de IA y LLM
* Familiaridad con los principios de desarrollo de software y los conceptos de API
* Experiencia con al menos un lenguaje de programación (se hará énfasis en ejemplos en Python o TypeScript)

Si quieres añadir una unidad nueva, **crea un issue en el repositorio describiendo la unidad y por qué debería añadirse**. La discutiremos y, si encaja, podemos colaborar en ella.
